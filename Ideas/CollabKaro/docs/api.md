# API Reference — CollabKaro

Base URL: `/api`

- `GET /api/creators` - List creators with filters (niche, followers, engagement).
- `GET /api/campaigns` - List active brand campaigns.
- `POST /api/campaigns` - Create a new campaign brief.
- `POST /api/proposals` - Submit a creator proposal for a campaign.
- `POST /api/milestones/:id/fund` - Fund milestone into escrow.
- `POST /api/milestones/:id/release` - Release milestone escrow payment to creator.
