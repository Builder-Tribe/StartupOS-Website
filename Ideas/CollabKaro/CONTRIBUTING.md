# Contributing to CollabKaro

Thank you for contributing to CollabKaro!

## 1. Branch Strategy
- `feat/<feature-name>` for new capabilities.
- `fix/<bug-name>` for fixes.

## 2. Pre-Commit Verification
1. Run syntax verification.
2. Ensure Express API routes handle errors gracefully.
3. Test full campaign & escrow flow in browser.
4. Update `ROADMAP.md` and `docs/` specs.
