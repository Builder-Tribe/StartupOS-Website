# CollabKaro — Build Documentation

**Idea Builder workspace:** `CollabKaro`

This documentation is the definitive product specification for **CollabKaro**, a full-stack, India-first marketplace and operating system for brand–creator partnerships.

Read in this order:

1. `01-master-prd.md` — complete product requirements and feature catalogue.
2. `02-competitor-research.md` — researched competitor capabilities and feature coverage decision log.
3. `03-technical-architecture.md` — backend, database, integrations, security, API, and hosting requirements.
4. `04-replit-build-plan.md` — phased Replit Agent instructions, test gates, and deployment instructions.

## Non-negotiable build rule

Build a working full-stack application. Do not deliver a click-through mockup, front-end-only interface, hard-coded dashboards, fake payments, or local-only state. Every stated workflow must persist in the database and enforce permissions on the server.

## Product in one sentence

CollabKaro lets a brand find or attract the right creators, agree commercial terms, manage briefs and content, track results, and make protected payouts; creators can get discovered, pitch brands, deliver work, and reliably receive payment.
