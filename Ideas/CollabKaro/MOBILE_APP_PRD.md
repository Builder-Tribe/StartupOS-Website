# CollabKaro Creator Mobile Application — Product Requirements Document (PRD)

> **Living Document.** This file defines the scope, user flows, tech stack, native features, and backend reuse contract for the **CollabKaro Creator Mobile App** (iOS & Android).

---

## 1. Executive Summary & Purpose

The **CollabKaro Mobile App** is a native iOS and Android application built specifically for **Creators, Influencers, UGC Creators, and Offline Event Hosts**.

While brands and platform administrators use desktop web browsers for campaign creation and analytics, creators are mobile-first. The mobile app enables creators to discover campaigns, receive real-time deal alerts, pitch custom rates, chat with brand managers, submit content proofs, and track earnings on the go.

---

## 2. Core User Personas & Mobile Journeys

| Persona | Key Mobile Goals | Core Screen Flows |
|---|---|---|
| **Nano / Micro Influencer** | Find open campaign calls, apply with one tap, submit Instagram Reel links | Onboarding → Campaign Feed → Application Form → Deal Chat → Payout |
| **UGC Creator** | Browse video brief requests, record/upload raw ad assets, track milestone payments | Brief Explorer → Offer Accept → Video Uploader → Milestone Wallet |
| **Offline / Event Creator** | Discover local store launches, check in via venue QR code, get paid | Map View / Local Events → Location Check-in → Live Proof → Instant Payout |

## 3. Technology Stack & Framework

- **Framework**: React Native + Expo (TypeScript)
- **State & Data Fetching**: React Context + custom React Hooks + REST API fetch client
- **Navigation**: React Navigation v6 (Bottom Tab Navigator + Native Stack)
- **Local Storage**: `expo-secure-store` for encrypted JWT tokens and user session data
- **Push Notifications**: Expo Notifications + Firebase Cloud Messaging (FCM) / APNs
- **Media & File Handling**: `expo-image-picker`, `expo-document-picker`, `expo-av` (video playback)
- **Location Services**: `expo-location` (for venue check-ins and regional campaign filtering)

## 4. Backend & API Reuse Contract (CRITICAL)

> [!IMPORTANT]
> **The mobile app is an extension of the existing backend API, NOT a separate project.**

### Strict Reuse Rules:
1. **Zero Duplicate Storage:** The mobile app relies on the existing Express REST API (`/api/v1/creators`, `/api/v1/campaigns`, `/api/v1/deals`). No second database or separate auth server.
2. **Shared JWT Realm:** Mobile authentication uses the exact same `creator` JWT realm (`ck_creator_token`) generated by the backend server.
3. **Additive Endpoints Only:** If mobile requires special payloads (e.g. device tokens for push notifications), extend existing Express routers additively in `server/src/routes/`.
4. **Token Parity:** Color tokens (`--brand`, `--surface`, `--accent`, `--text-primary`) and font scales must match the web design system tokens in `web/src/styles/`.

## 5. Mobile App Features & Modules

### 5.1 Mobile Onboarding & Authentication
- Mobile OTP sign-in (SMS via Indian gateway) + Email/Password fallback.
- Social profile connection wizard (Instagram Graph API, YouTube Data API, LinkedIn).
- Secure JWT persistence via `expo-secure-store`.

### 5.2 Campaign Discovery & Feed
- Algorithmic feed tailored to creator niche, city, follower range, and content format.
- Filter by platform (Instagram, YouTube, UGC, Offline Event), compensation (Paid, Barter, Commission), and turnaround time.
- One-tap pitch submission with custom media kit attachment.

### 5.3 Mobile Deal Room & Realtime Messaging
- In-app chat with brand campaign managers.
- Media proof submission (upload video drafts, link Instagram Reels, attach invoice).
- Real-time status badges (Drafting → Review → Approved → Paid).

### 5.4 Offline Event & Store Visit Check-in
- GPS-verified venue check-in for offline activation campaigns.
- In-app QR code scanner for event host verification.

### 5.5 Creator Wallet & Instant UPI Payout
- View earned balance, pending escrow funds, and tax deductions (TDS).
- One-click withdrawal request to UPI ID or bank account.
