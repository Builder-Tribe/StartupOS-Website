# Frontend Architecture — BusinessPay

- **Stack:** React 19, Vite 8, Tailwind CSS design tokens.
- **State Management:** Local React state + hooks + async fetch API wrappers.
- **UI Components:**
  - `StatsHeader`: Top KPI cards displaying AR metrics.
  - `InvoicesTable`: Data table with filters and status badges.
  - `InvoiceDrawer`: Slide-over drawer for deep-dive invoice & customer details.
  - `BuyerPortalModal`: Simulated buyer payment view.
